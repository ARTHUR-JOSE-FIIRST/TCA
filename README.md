O projeto consiste no desenvolvimento de um jogo de Sudoku utilizando a linguagem de programação Java. O objetivo é criar uma aplicação interativa que permita ao usuário jogar Sudoku em dois tamanhos de matrizes diferentes: 6x6 e 9x9.

<img width="495" height="774" alt="image" src="https://github.com/user-attachments/assets/b11f70e4-a49a-452d-bc4a-e63f5950e8d7" />

O sistema permitirá que o jogador escolha o tamanho da matriz e preencha os espaços vazios com números, respeitando as regras de cada modalidade. O jogo contará com verificações para garantir que os números inseridos estejam corretos, evitando repetições nas linhas, colunas e regiões determinadas.

Além do modo tradicional, o jogo contará com um sistema de tempo para cada rodada, no qual o jogador deverá resolver o Sudoku antes que o tempo se esgote. Também haverá um modo de desafio, em que um conjunto de números da matriz desaparecerá após determinados intervalos de tempo, aumentando a dificuldade e exigindo mais atenção e raciocínio lógico do jogador.
